## Instit 2.0.0

- Remplacement du backend Supabase par Firebase Authentication, Cloud Firestore et Cloud Functions.
- Synchronisation local-first conservée, avec travail hors ligne et reprise sécurisée.
- Hébergement du site et de l’application Web sur Firebase Hosting.
- Journal de classe quotidien simplifié et leçons organisées en espaces de cours.
- Facturation applicative désactivée pour cette version.

Les anciennes données Supabase ne sont pas importées : la cible Firebase démarre vide.
